💧 SO101 Water Pouring Robot (AI-Based Imitation Learning)
📌 Overview

This project presents an AI-driven robotic system capable of performing a water pouring task using the SO101 robotic arm. The robot learns the task through imitation learning, where human demonstrations are captured via teleoperation and used to train a model for autonomous execution.

🚀 Key Features
🤖 Leader-Follower Teleoperation System
🎥 Vision-based Data Collection (Camera Input)<img width="1211" height="678" alt="b3633b31-88c7-4920-9b5b-a6aef8fd7822" src="https://github.com/user-attachments/assets/6e439ef4-5204-433d-b028-8cd2870d28a4" />

🧠 Imitation Learning using LeRobot
💧 Smooth and Controlled Pouring Motion
⚙️ Autonomous Task Execution
🎯 Objective

To enable a robotic arm to pick a container and pour water into another container accurately, minimizing spillage and ensuring smooth motion.

🛠️ Technology Stack
Python 3.10+
LeRobot (Hugging Face Robotics Framework)
PyTorch (Deep Learning)
OpenCV (Camera Interface)
Solo CLI (Robot Control)
